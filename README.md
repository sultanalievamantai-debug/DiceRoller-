# 🎲 DiceRoller

> Виртуальный бросок шестигранного кубика — с историей и статистикой.

## 🎯 О проекте

Мини-приложение на чистом JavaScript: нажимаешь кнопку — 
кубик «бросается», показывается результат, а все броски 
записываются в историю с подсчетом суммы.

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как играть

1. Открой `index.html` в браузере
2. Нажми **«Бросить»** — кубик покажет случайное значение от 1 до 6
3. Смотри статистику: сколько бросков сделано и какая сумма
4. Нажми **«Сбросить»** — история и счет обнулятся
